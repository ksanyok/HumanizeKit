REST API

Integrate HumanizeKit into your workflow

POST
/api/humanize

Transform text to sound more natural

Parameters
ParameterTypeRequiredDescription
textstring✅The text to humanize
langstring—Language code (auto, ru, uk, en, de, fr, es, pl, pt, it). Default: auto-detect
profilestring—Processing profile: chat, web, seo, docs, formal. Default: web
intensityint—Processing intensity 0-100. Default: 60
keep_keywordsarray—Words/phrases to preserve unchanged
Request
curl -X POST https://humanizekit.tester-buyreadysite.website/api/humanize \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Furthermore, it is important to note that the implementation of cloud computing facilitates optimization.",
    "lang": "auto",
    "keep_keywords": ["API"]
  }'
Response
{
  "ok": true,
  "text": "Cloud computing really helps optimize...",
  "detected_lang": "en",
  "change_ratio": 0.32,
  "changes": [
    {"stage": "Debureau", "old": "Furthermore", "new": "Also"},
    {"stage": "Debureau", "old": "facilitates", "new": "helps"}
  ],
  "metrics_before": {...},
  "metrics_after": {...},
  "elapsed_ms": 42
}

POST
/api/extract

Extract text from uploaded files or URLs

Request
# File upload
curl -X POST /api/extract \
  -F "file=@document.txt"

# URL extraction
curl -X POST /api/extract \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/article"}'
Response
{
  "ok": true,
  "text": "Extracted text content...",
  "source": "url",
  "url": "https://example.com/article",
  "chars": 1234
}
